# WebDrop 快速傳送（Chrome 擴充功能）

右鍵傳送圖片/連結/選取文字到 WebDrop，或拖曳檔案到頁面上的浮動按鈕快速傳送——都是透過已開啟且已加入房間的 WebDrop 分頁來傳送，本身不重新實作連線邏輯。

## 安裝方式（開發者模式載入）

1. 開啟 Chrome，網址列輸入 `chrome://extensions`
2. 右上角開啟「開發人員模式」
3. 點「載入未封裝項目」，選擇這個 `extension` 資料夾
4. 圖示會出現在工具列上

## 使用方式

1. 先在瀏覽器開一個分頁，前往 `https://webdrop-6l1u.onrender.com/` 並加入或建立房間
2. 右鍵點圖片 / 連結 / 選取文字 → 選單裡的「傳送到 WebDrop」選項
3. 或者在任何網頁把檔案拖曳到畫面右下角的小圖示上放開
4. 點工具列的擴充功能圖示可以看目前房間代碼、QR Code、連線狀態

## 限制

- 需要有一個分頁已開啟 WebDrop 網站且已加入房間，擴充功能不會自己連線
- 瀏覽器（任何家）都不支援把檔案拖放到工具列圖示上，所以改成頁面內的浮動投遞按鈕
- 目前寫死正式站網址 `https://webdrop-6l1u.onrender.com`，之後若換網域要同步更新 `manifest.json`、`background.js`、`popup.js`
